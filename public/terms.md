1.1. Ці умови користування регулюють доступ до сервера M4SUB, вебсайту та пов’язаних сервісів (далі — «Сервіси»).

1.3. Використовуючи наші сервіси, ви підтверджуєте, що ознайомилися, зрозуміли та беззастережно приймаєте ці Умови, а також [Політику конфіденційності](./privacy.md).

## 2. Доступ до сервісу та безпека акаунта

2.1. Сервер M4SUB призначений для гри в Minecraft Java Edition. Для доступу до гри користувач повинен мати ліцензійну копію гри або використовувати офіційно сумісне програмне забезпечення (лаунчер).
2.2. Користувач несе повну персональну відповідальність за безпеку свого ігрового акаунту, пароля та доступу до Discord-профілю. 
2.3. Будь-які дії, вчинені з вашого акаунту (включаючи порушення правил чи здійснення платежів), вважаються вчиненими вами особисто.
2.4. Адміністрація залишає за собою право тимчасово або назавжди обмежити (заблокувати) доступ користувача до Сервісів у разі порушення цих Умов або правил спільноти без попередження та компенсацій.
2.5. Окремі ігрові режими (сервери) в мережі M4SUB можуть мати додаткові локальні правила — детальніше дивіться відповідні розділи на сайті або в Discord.

## 3. Поведінка користувачів

Користувачі проєкту M4SUB зобов’язані:
* Дотримуватися загальних [правил сервера](/rules).
* Не використовувати чити, модифікації, макроси, експлойти (баги гри) та будь-які інші засоби, що дають нечесну перевагу над іншими гравцями або шкодять стабільності сервера.
* Не намагатися дестабілізувати роботу серверної інфраструктури, вебсайту або платіжних шлюзів.
* Поважати інших гравців та команду проєкту. Категорично заборонено прояви токсичності, образи, розпалювання ворожнечі, спам та рекламу сторонніх ресурсів.

## 4. Донати, покупки та платіжні операції

Оскільки M4SUB є некомерційним ігровим проєктом, який утримується на ентузіазмі розробників, фінансові операції на сайті є **добровільними пожертвами** (донатами) на підтримку та розвиток серверів.

### 4.1. Проведення платежів через Monobank API
* Усі платежі здійснюються в автоматичному або напівавтоматичному режимі через офіційне та безпечне **API Monobank** (АТ «УНІВЕРСАЛ БАНК»).
* При здійсненні оплати ви будете перенаправлені на захищену сторінку банку. Проєкт M4SUB не збирає та не зберігає дані ваших банківських карток.

### 4.2. Отримання цифрового контенту
* На знак подяки за добровільну підтримку користувачу надається віртуальний ігровий контент (ігрова валюта, привілеї, статуси або косметичні предмети) відповідно до опису на сторінці [магазину](/donate).
* Термін зарахування покупок зазвичай становить від 5 до 15 хвилин після успішної транзакції через API банку. У разі затримок користувач має право звернутися до техпідтримки в Discord.

### 4.3. Політика скасування та повернення коштів
* Оскільки придбаний контент є цифровим товаром миттєвого споживання, **повернення коштів не здійснюється**. 
* Здійснюючи платіж, ви підтверджуєте, що робите це добровільно, усвідомлено та відмовляєтеся від права вимагати повернення (chargeback).
* Блокування акаунта за порушення [правил сервера](/rules) не є підставою для повернення коштів за придбані раніше товари чи привілеї.

## 5. Ігрові вайпи та технічні роботи

5.1. Для підтримки стабільності, оновлення версій гри або покращення ігрового балансу, Адміністрація має право проводити **«вайпи» (wipe)** — повне або часткове очищення ігрового світу, інвентарів, прогресу та балансів гравців.
5.2. Проведення планового вайпу не є підставою для повернення коштів. При цьому куплені унікальні привілеї (наприклад, постійні донат-ранги) зберігаються за акаунтом гравця, якщо інше не було чітко вказано в описі товару в [магазині](/donate).

## 6. Обмеження відповідальності

6.1. Проєкт M4SUB надається за принципом **«як є»** (as is). Адміністрація не гарантує безперебійну роботу сервісів 24/7 та відсутність помилок.
6.2. Адміністрація не несе відповідальності за втрату ігрового прогресу, предметів, внутрішньоігрової валюти чи приватних територій, що сталися внаслідок:
* Технічних збоїв у роботі хостингу або бази даних.
* Проведення планових технічних робіт чи вайпів.
* Дій третіх осіб (включаючи злам акаунтів через слабкі паролі).
* Ігрових механік (наприклад, очищення предметів на землі для оптимізації).
6.3. Адміністрація не несе відповідальності за затримки або збої у проведенні платежів, що виникли на стороні платіжного провайдера (Monobank) або банку-емітента користувача.
